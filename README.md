# 📋 Task Management Web

A full-stack task management web application designed to help users organize, schedule, and track daily tasks efficiently. Built with the MERN stack and styled using Tailwind CSS.

---

## ✨ Features

- ➕ **Create & Save Tasks**: Add new tasks with titles, descriptions, and deadlines.
- ✏️ **Edit Tasks**: Update existing task details, statuses, and notes in real time.
- 🗑️ **Remove Tasks**: Delete completed or obsolete tasks with immediate database sync.
- ⏰ **Task Scheduling**: Assign due dates and organize tasks by timeline and priority.
- 📱 **Responsive Design**: Clean, modern interface optimized for desktop and mobile devices.

---

## 🛠️ Tech Stack

### Frontend
- ⚛️ **React (JSX)**: Component-based user interface and state management.
- 🎨 **Tailwind CSS**: Utility-first CSS framework for styling and layout.

### Backend
- 🟢 **Node.js**: Server-side runtime environment.
- 🚂 **Express.js**: RESTful API routing and middleware handling.

### Database
- 🍃 **MongoDB**: NoSQL database for persistent storage of task records.
- 🔌 **Mongoose**: Object Data Modeling (ODM) library for MongoDB.
